# مرآة | الملف الشامل

منصة **استعلام فقط** ضمن منظومة **النواة الرقمية** في متوسطة لبيد بن ربيعة المتوسطة. تجمع السجلات والإجراءات المرتبطة بمتعلم أو معلم من الأنظمة القائمة، وتعرضها في ملف واحد قابل للطباعة والتصدير PDF.

> الملف الشامل نافذة موحدة على البيانات الموجودة، وليس مصدراً جديداً لإنشاء البيانات.

- **لا قاعدة بيانات جديدة ولا جداول:** طبقة القراءة دوال `mr_*` فقط في قاعدة النواة (`labeedsch_PC`).
- **لا إدخال:** لا نماذج، ولا إضافة أو تعديل أو حذف. البحث والتصفية فقط.
- **الربط بالمعرّف الموحد** في النواة (`students.id` و`staff_members.id`)، وليس بالاسم.
- **لكل سجل مصدره:** النظام المصدر ظاهر في كل قسم وفي كل حدث من السجل الزمني.
- **الكتابة على البيانات:** لا شيء. يُكتب فقط سطر في سجل عمليات النواة (`audit_logs`) عند الاطلاع (`VIEW`) والتصدير (`EXPORT`) ورفض الوصول (`DENIED`) وتعديل الصلاحيات (`PERMISSION`).
- **التقرير مذيّل باسم صاحب الحساب:** كل صفحة من تقرير PDF تحمل في تذييلها «صدر التقرير من حساب: <الاسم>»، مع التاريخ والترقيم.

## الأنظمة المقروءة
| الملف | الأنظمة |
|---|---|
| المتعلم | النواة (التعريف والقيود الدراسية)، انضباطي (الحضور، التأخر، الأعذار، الإجراءات النظامية، الإشعارات، نقاط الانتظام)، قيمي (التعزيز، الأوسمة، السلوك الإيجابي، دفتر النقاط، الحالات السلوكية، الإجراءات التربوية، برامج التدخل، الخطط الإرشادية، سجل التحسن، الإنجازات، المواهب) |
| المعلم | النواة (البيانات الوظيفية، التاريخ الوظيفي، السجل السنوي، المواقع القيادية، الأدوار، المرافق المسؤول عنها)، مجتمع لبيد المهني (الملف المهني، خطط النمو، النمو المهني، السيرة المهنية، المجتمعات، اللقاءات، المبادرات، المخرجات)، التقويم الذاتي (الفريق، الإسنادات، المهام، الزيارات الفنية، الشواهد، إجراءات التحسين، الاجتماعات)، الخطط الذكية (إسنادات الخطط والبرامج)، احجز مرفق (الحجوزات)، انضباطي (التكليفات)، والإسهام في قيمي وانضباطي (أعداد مجمّعة دون أسماء طلاب) |

التفاصيل والحقول في [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

## الصلاحيات
الاطلاع نوعان مستقلان، يُمنحان من لوحة **«المصرح لهم»** (`perms.html`) في مرآة بوضع علامة لكل منسوب:

| الصلاحية | الرمز في النواة | ما تتيحه |
|---|---|---|
| تقرير المتعلم | `mirat:view_student` | البحث عن المتعلمين وفتح ملفاتهم الشاملة واستخراج تقاريرها |
| تقرير المعلم | `mirat:view_staff` | البحث عن منسوبي المدرسة وفتح ملفاتهم الشاملة واستخراج تقاريرها |
| منسق مرآة | `mirat:approve` | إدارة لوحة المصرح لهم، ويطّلع على النوعين |

| من | ماذا يرى |
|---|---|
| مدير النواة ومدير المدرسة | كل الملفات وكل الأقسام، ويديران اللوحة، ويعيّنان منسق مرآة |
| منسق مرآة | النوعان، ويدير صلاحيتي التقرير لمنسوبي المدرسة (دون تعيين المنسقين) |
| من مُنح تقرير المتعلم أو تقرير المعلم | ملفات ذلك النوع فقط، عدا الأقسام الحساسة إن لم يملك صلاحية نظامها |
| `mirat:view` (الصلاحية السابقة) | النوعان معاً، وتتحول إلى الصلاحيتين الجديدتين عند أول تعديل من اللوحة |
| الأقسام الحساسة | الحالات السلوكية وبرامج التدخل والخطط الإرشادية: وكيل شؤون الطلاب والموجه في قيمي. الأعذار: منسق الغياب وشؤون الطلاب في انضباطي. التواصل وأولياء الأمور: `students_contact:view`. تاريخ الميلاد والجنسية: `students:view`. الرقم الوظيفي: `personnel:view`. تواصل المنسوب: `personnel_contact:view` |
| غيرهم | رسالة «لا تملك صلاحية» دون أي بيانات، ويُسجَّل الرفض |

الصلاحية تُتحقق في الخادم في كل دالة (البحث، الملف، التصدير)، لا في الواجهة فقط.
القسم المقيد يظهر بعبارة صريحة، ولا تُعرض بدلاً منه أي بيانات.

## البنية
| المسار | المحتوى |
|---|---|
| `site/` | واجهة ثابتة (HTML وJS بلا أداة بناء) على GitHub Pages |
| `site/index.html` | الصفحة الرئيسية العامة: خدمات الملف الشامل ومصادره ومبادئه |
| `site/about.html` | «عن مرآة»: التعريف، وسبب النشأة، والرؤية، ورحلة الملف، والمزايا، والمستفيدون، والأسئلة |
| `site/search.html` | البحث الموحد (بعد الدخول): متعلم أو معلم |
| `site/profile.html` | الملف الشامل: قائمة الأنظمة المعروضة (صف لكل نظام، بمربع لإظهاره كله ولسان يُفتح على أقسامه، بتحديث مباشر)، ثم الملخص، والأقسام التفصيلية، والسجل الزمني الموحد. الاختيار مشترك مع التقرير |
| `site/perms.html` | «المصرح لهم» (لمدير النواة ومدير المدرسة ومنسق مرآة): كل منسوبي المدرسة الفعّالين، ومربعا «تقرير المتعلم» و«تقرير المعلم» لكل منسوب، ويُحفظ التغيير فوراً |
| `site/report.html` | معاينة التقرير واختيار محتواه (الأجزاء، والأنظمة بالصفوف القابلة للطي نفسها وأقسامها مرقّمة، والافتراضي الكل)، ثم التصدير PDF: A4 عمودي، هوامش 15 مم |
| `site/assets/acc.css` | قائمة الأنظمة القابلة للطي، مشتركة بين الملف ولوحة التقرير. والواجهة كلها مهيأة للجوال (تُختبر على عرض 390 بكسل) |
| `supabase/migrations/` | `0400` تسجيل النظام وصلاحيته، `0401` طبقة القراءة، `0402` تفاصيل ملف المعلم (الخطط الذكية والمؤشرات المسندة)، `0403` صلاحيات المصرح لهم ولوحتها |
| `tests/` | اختبارات القاعدة (`run.sh`)، واختبارات الواجهة وPDF بمتصفح حقيقي (`e2e/`) |

## التشغيل المحلي والاختبار
```bash
PGHOST=/tmp/pg PGPORT=5544 tests/run.sh            # نسخة هيكلية من النواة + الترحيلات مرتين + الاختبارات
PGHOST=/tmp/pg PGPORT=5544 tests/e2e/reset.sh      # قاعدة معاينة ببيانات اختبار + خادم http://localhost:8787
PGHOST=/tmp/pg PGPORT=5544 node tests/e2e/run.js   # الواجهة وPDF (Playwright + poppler-utils)
```
